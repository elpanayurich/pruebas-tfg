#  Pruebas TFG

Este repositorio contiene las pruebas y simulaciones para mi **Trabajo de Fin de Grado (TFG)**. El proyecto se centra en la simulación de entornos Cell-Free Massive MIMO con RIS (Reconfigurable Intelligent Surfaces). Se busca conseguir un algoritmo capaz de asignar las RISs de una forma eficiente y funcional para cualquier entorno CF-mMIMO.

##  Estado del Proyecto: En Desarrollo

Este proyecto se encuentra actualmente **en desarrollo**. Mantengo todas las versiones anteriores para seguimiento, control de cambios y capacidad flexible de testing.

###  Versiones
- Las carpetas están numeradas cronológicamente (`prueba1`, `prueba2`, etc.).
- **La versión más reciente y actualizada se encuentra siempre en la carpeta con el número más alto**. Aunque puede que alguna pruebaX sea únicamente un test aleatorio.
